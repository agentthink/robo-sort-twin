平台新增发布器验证包含会话启停、冻结图像在后台编码 JPEG、产品身份与 TCP 写入标志、重连恢复、离线非阻塞队列和后台取消退出。

跨进程验证使用原平台测试程序中的真实遥测发布器，与沙盘的真实命名管道接收器通信。发送三条合成采样及停止状态，没有连接实体相机或机器人。相机驱动、现场照明、坐标标定、实体抓取和厂商机器人协议不在本次硬件验收范围。

受限执行环境最初拒绝命名管道和 TCP 回环访问；上述通信验证在获准的正常 Windows 环境中运行通过。
